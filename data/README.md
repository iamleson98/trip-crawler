# Crawl Datasets & Excel Workbooks

This directory holds the published crawl outputs and Excel workbooks
produced by the Python scripts in `../scripts/`.

> **Data accuracy note (hidden pickup points).** The `/v2/route/` search API
> attaches each operator's *entire* point pool to every trip — e.g. trips of
> "Anh Huy Đất Cảng" (company 12847) carry 1,953 pickup points, while route
> 7275428 (Hải Phòng → Hà Nội) actually serves exactly 1 ("Bến xe Thượng Lý").
> The website only renders points whose top-level `hidden` flag is `0`.
> The crawler now filters hidden points at the API layer
> (`vexerers::api::trips::strip_hidden_points`) and the Excel/SQLite builders
> apply the same filter defensively, so every artifact here matches what
> vexere.com shows.

## Files

| File | Size | Description |
|------|------|-------------|
| `vexere_nxn_manifest.json` | ~16 KB | Inventory of all 72 (from, to) pairs attempted: from/to city IDs, names, trip count, fare count, output paths. |
| `vexere_nxn_trips.xlsx` | ~5.4 MB | **Flat fares workbook** — 62 sheets: 1 summary + 60 per-pair (skips the 12 pairs that had zero direct service). 84,034 fare rows, 13 columns each. |
| `vexere_nxn_trips_enriched.xlsx` | ~10.7 MB | **Enriched workbook** — 62 sheets: 1 summary + 60 per-pair + 1 master "Pickup & Dropoff Points" sheet. 42,017 enriched fares with 25 columns each, plus 6,873 distinct pickup/dropoff points (website-visible only). |
| `booking_seed.sqlite` | ~21 MB | **Booking-app seed database** — the enriched workbook loaded into the full booking-app schema (all 38 tables, SeaORM-compatible). Deduplicated, see below. |
| `booking_seed_reverse_geocode_cache.json` | ~550 KB | Reverse-geocode cache (2,469 unique coordinates → province/ward) from `datxevui.com`, used to fill `address.province/district/ward`. Keep next to the script to re-seed without API calls. |

## `booking_seed.sqlite` — booking-app seed database

Generated by [`../scripts/seed_booking_db.py`](../scripts/seed_booking_db.py)
from `vexere_nxn_trips_enriched.xlsx`:

| Table | Rows | Identity (deduplicated) |
|-------|------|------------------------|
| `brand` | 306 | operator name (case/space-insensitive) |
| `route` | 1,093 | (brand, from-city, to-city); `start/end_location_id` = VIETNAMESE_CITIES ids |
| `bus_layout` | 525 | (brand, vehicle label, total seats) |
| `address` | 3,832 | (brand, normalized name) + 2 km geo-cluster; coords = most-seen pair; province/ward via reverse geocoding (3,692 with province) |
| `schedule` | 9,676 | (route, departure_time, bus_layout) — one recurring service; days_of_week + effective_from/to across all observed dates; base_price_adult = min fare |
| `schedule_point` | 63,786 | (schedule, stop_order); kind = pickup/middle/drop; arrival_time = `T0`, `T+135min`, `T-50min` (modal offset across dates) |

Duplicate prevention: five UNIQUE indexes (`ux_route_ident`,
`ux_bus_layout_ident`, `ux_address_ident`, `ux_schedule_service`,
`ux_schedule_point_stop`) enforce the identities above at insert time, and
the script's verification report fails the run if any duplicate check,
foreign key, or T(N) format check regresses.

Caveat: 476 schedules (the route-level point-aggregation rows guarded by
`--max-declared-points`, e.g. Anh Huy Đất Cảng route 7275428) intentionally
carry no schedule_points; re-crawling with the hidden-points fix
(`strip_hidden_points`) and re-running the seed fills them in.

Update: `brand.logo_url` is now filled for 275/306 brands (the operator
cover image VeXeRe shows on trip cards) — set by
[`../scripts/fetch_vehicle_media.py`](../scripts/fetch_vehicle_media.py).

## `vehicle-type-media/` — VeXeRe vehicle-type pictures

VeXeRe serves a captioned photo gallery per **(company, seat-template)** —
i.e. per vehicle type of each operator — via

    GET https://api.vexere.com/v3/company/{company_id}/media
        ?resource_id={seat_template_id}        (anonymous bearer token)

Harvested by [`../scripts/fetch_vehicle_media.py`](../scripts/fetch_vehicle_media.py)
across all 72 N×N pairs × 4 search dates:

| Item | Count |
|------|-------|
| companies (operators) | 303 (280 matched to seed brands by name) |
| vehicle types (seat templates) | 509 — labels match `bus_layout.name`, e.g. "Limousine giường phòng 21 chỗ (WC)" |
| unique images (all downloaded locally) | 4,074 (4,057 JPEG + 17 PNG) |
| cover images committed here | 502 (first image of each vehicle type, ~42 MB) |

| File | Description |
|------|-------------|
| `vehicle_type_media.json` | Full manifest: per company → vehicle types → images (image_id, original URL, caption vi/en, local file when downloaded). `brand_slug` joins to `booking_seed.sqlite.brand`; `label` joins to `bus_layout.name`. |
| `vehicle_images.html` | Review gallery — every vehicle type with its photos (missing local files fall back to the VeXeRe CDN URL). |
| `vehicle_images/` | The committed cover image per vehicle type (1 per type). The complete 4,074-image set (~350 MB) is produced by re-running the script — every URL is in the manifest. |

Captions describe vehicle parts (mặt trước / bên hông / nội thất / tiện
ích — front, side, interior, amenities) and are in the manifest per image.

## Coverage of the N×N dataset

- **9 cities, 72 ordered pairs** (each city paired with every other city).
- **3-day window**: 2026-09-09 → 2026-09-11.
- **60 pairs** have direct service (41,993 trips total).
- **12 pairs** have no direct service — mostly cross-region pairs that
  are geographically far (e.g. Hà Giang → Nha Trang, Đà Lạt → Hà Giang).
